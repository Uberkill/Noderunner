# AI Agent Instructions for Radial Stream

Greetings, Agent. When modifying or expanding this codebase, you must adhere strictly to these architectural rules and system design principles. This project is optimized for performance, scalability, and specific aesthetics. 

## 1. Dependency Management
- **Installation**: Always use `npm install <package> --legacy-peer-deps`. The `@react-three/drei` and `postprocessing` libraries have tight peer dependency requirements that will fail a standard `npm install`.

## 2. Global State via Zustand
- The legacy `App.jsx` used to be a massive state container. This was refactored out.
- **DO NOT** re-introduce prop-drilling or React Context for global state.
- **DO NOT** use local `useState` for anything that needs to cross the WebGL/DOM boundary.
- **DO** use `src/core/store.js`. When importing, destructure only what is needed to avoid global re-renders.

## 3. The WebGL / DOM Boundary
- `Scene.jsx` (and its children) live in WebGL space (`<Canvas>`).
- HTML Overlays live in DOM space.
- The two spaces communicate entirely via `zustand`. Do not attempt to mount DOM elements deeply within the 3D scene unless you are explicitly using Drei's `<Html>` component for labels (like in `DataPoint.jsx`).

## 4. Performance & Memory Strictness
Memory leaks are the #1 enemy of this project.
- **WebGL**: Avoid imperative `new THREE.BufferGeometry()` in render loops or frequent re-renders. Use declarative JSX (`<bufferGeometry>`, `<bufferAttribute>`) when possible so React Three Fiber handles garbage collection automatically.
- **Audio**: The `AudioManager` generates oscillators programmatically. If you add new continuous drones/pads, you must ensure they are pushed to the `activeDepthNodes` array or properly garbage collected via `.stop()` and `.disconnect()`.
- **Tick Loops**: `useFrame` runs 60+ times a second. **NEVER** instantiate arrays, objects, or `THREE.Vector3` instances inside it. Pre-allocate vectors outside the component or at the module level.

## 5. Aesthetics & Lore
- The tone is retro-futuristic, cryptic, and professional. 
- Avoid generic UI. Everything should look like an old CRT terminal or a high-tech diagnostic HUD.
- The lore expands via `StoryGenerator.js`. Follow the established format for procedurally generated node descriptions.

## 6. Using Graphify
- This project utilizes the **Graphify** MCP for maintaining a semantic knowledge graph of its architecture.
- If you add major new files, features, or architectural patterns, check if the graph needs updating.

Acknowledge these rules before initiating a plan.
